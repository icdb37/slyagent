# slyagent
基于 anthropic 兼容大模型接口实现的简化版 ai agent

## 功能描述
* ReAct 交互 和 SSE（Server-Sent Events） 流式输出
* 函数调用和工具调用
* 历史记录压缩
* tui

### TUI
分为3块：交互历史记录、输入框、状态展示

```
╔══════════════════════════════════════════╗
║ slyagent                 claude          ║
╠══════════════════════════════════════════╣
║                                          ║
║  > 你好，请介绍一下自己                  ║
║                                          ║
║  ◀ 助手                                  ║
║  ──────────────────────────────────────  ║
║  你好！我是 Claude，一个 AI 助手...      ║
║                                          ║
║  > 执行 echo "hello world"               ║
║                                          ║
║  ◀ 助手                                  ║
║  ──────────────────────────────────────  ║
║  调用工具: shell                         ║
║  ┌────────────────────────────────┐      ║
║  │ $ echo "hello world"           │      ║
║  │ → hello world                  │      ║
║  └────────────────────────────────┘      ║
║  执行成功了。                    ▍       ║
║                                          ║
╠══════════════════════════════════════════╣
║ > █                                      ║
╠══════════════════════════════════════════╣
║ ✓ 就绪 │ tokens: 1.2k │ 5/20 │ 压缩:关   ║
╚══════════════════════════════════════════╝
```

* **交互历史记录**（中部，可滚动）：用户消息以 `>` 开头；助手回复以 `◀` 开头，末尾 `▍` 表示 SSE 流式输出光标；工具调用以嵌套框展示命令与结果
* **输入框**（底部）：单行编辑，`Enter` 发送，`Ctrl+D` 多行，`Esc` 取消
* **状态展示**：
  * 顶部：应用名 + 当前模型
  * 底部：运行状态 / token 用量 / 历史条数 / 压缩开关
